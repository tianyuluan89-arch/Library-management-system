# LibrarySystem
Library management system software design project.

## Project Overview
This project is a design for a library management system.
The system supports book borrowing, book returning, viewing available books and recording borrow records.
No implemented source code, this repository only contains software design documents and UML diagrams.

## Design Contents
1. Requirement analysis
2. Use case diagram
3. Class diagram
4. Component diagram
5. Test plan and test cases

## Repository Information
This repo stores all design artifacts for the library system.
