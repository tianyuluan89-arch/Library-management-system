# Actors of Library Management System
1. Reader
- Role: Library user
- Interactions: View book list, borrow books, return books, check personal borrowing records.

2. Librarian
- Role: Library staff
- Interactions: Add new books, modify book information, verify borrow and return operations.

3. System Administrator
- Role: System manager
- Interactions: Manage reader accounts, maintain system data, handle system configuration.
