# Use Case Diagram for Library Management System
## Actors
1. LibraryUser
Description: Library reader, can search books, borrow and return books.
2. Librarian
Description: Library staff, manage book inventory and view borrowing records.

## List of Use Cases
1. Search Book
Actor: LibraryUser, Librarian
Description: Search book by title or author, view available quantity.

2. Borrow Book
Actor: LibraryUser
Description: Borrow available books, create borrow record.

3. Return Book
Actor: LibraryUser
Description: Return borrowed books and update borrow record.

4. Add New Book
Actor: Librarian
Description: Add new book information into system.

5. Edit Book Information
Actor: Librarian
Description: Modify book title, author and other information.

6. Delete Book
Actor: Librarian
Description: Remove book record from library system.

7. View Borrow Record
Actor: Librarian
Description: Check all borrowing and returning history records.
